# Sleek & Modern UI Overhaul

ส่วนขยาย (Extension) ปรับแต่งอินเทอร์เฟซผู้ใช้สำหรับ **SillyTavern** ให้ดูทันสมัย สวยงาม มินิมอล พร้อมรองรับการเปลี่ยนสีตามธีมหลัก (Dynamic Theme) และปรับแต่งเค้าโครงส่วนประกอบต่างๆ ให้ใช้งานง่ายยิ่งขึ้น

---

## ✨ คุณสมบัติหลัก (Key Features)

* **Dynamic Theme Integration:** 
  * ปรับเปลี่ยนโทนสีของข้อความ กล่องแชต และเส้นไฮไลต์ข้างข้อความ (Accent Borders) ตาม SmartTheme ของ SillyTavern โดยอัตโนมัติ
* **Compact & Rounded Top Bar:**
  * ปรับย่อความสูงของ Top Bar ลงเหลือ 40px เพิ่มความโค้งมนที่ขอบล่าง ซ่อนเส้นขอบส่วนเกิน และเพิ่มมิติด้วยแสงเงา
* **Right-Aligned User Messages:**
  * จัดเค้าโครงฝั่งผู้ใช้ (User Message) ใหม่ให้ชิดขวา พร้อมสลับตำแหน่งรูปโปรไฟล์และชื่อมาอยู่ฝั่งขวาอย่างสวยงาม
* **Custom Chat Bubbles & Avatars:**
  * ปรับแต่งกล่องแชตและรูปโปรไฟล์ให้โค้งมน ดูนุ่มนวล พร้อมเอฟเฟกต์ Glassmorphism (Blur Background)
* **Custom Scrollbars & Clean Drawers:**
  * ปรับแต่งเมนูดรอปดาวน์และแผงควบคุมด้านข้างให้โค้งมนและสะอาดตา
