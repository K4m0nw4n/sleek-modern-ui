# Sleek & Modern UI Extension for SillyTavern

ส่วนขยายปรับแต่งหน้าจอ (UI/UX) สำหรับ **SillyTavern** เน้นสไตล์มินิมอล ดาร์กโหมด กระจกโปร่งแสง (Glassmorphism) และเครื่องมือช่วยพิมพ์สำหรับการเล่น Roleplay

---

## ✨ ฟีเจอร์หลัก

- **ไฮไลต์สีตามธีมหลัก (Dynamic Theme Colors)**: ดึงค่าสีจากระบบธีมของ SillyTavern มาใช้กับเส้นขอบ ข้อความคำพูด และสถานะต่างๆ โดยอัตโนมัติ
- **กล่องแชตฝั่ง User จัดชิดขวา**: ปรับข้อความ รูปโปรไฟล์ และชื่อของผู้ใช้ให้จัดวางชิดขวาเพื่อความสวยงาม เป็นสัดส่วนสไตล์แอปแชตโมเดิร์น
- **จุดไฟสถานะ Online**: เพิ่มจุดไฟเรืองแสงสีเขียวบริเวณรูปโปรไฟล์ของตัวละคร AI
- **Quick Insert Toolbar (แถบแทรกสัญลักษณ์ด่วน)**: ปุ่มลอยเหนือช่องพิมพ์ (`"..."`, `*...*`, `(...)`) กดแทรกสัญลักษณ์ครอบข้อความ หรือย้ายเคอร์เซอร์ไปตรงกลางให้อัตโนมัติ
